Fabric is a color theme after Dieter Rams' Braun products, in two variants:
dusk and dawn.

## Resources

- [DESIGN-fabric.md](DESIGN-fabric.md): the canonical design document
- [dist/palette.json](dist/palette.json): both variants as machine-readable
  tokens; integrations pin a release tag and fetch this file
- [fabric-ghostty](https://github.com/ozzycodes2/fabric-ghostty): the Ghostty
  integration

## Contributing

To add an integration, use the submission form on the
[Fabric site](https://github.com/ozzycodes2/fabric-site). Integrations build from
`dist/palette.json` at a release tag rather than copying hex values.
